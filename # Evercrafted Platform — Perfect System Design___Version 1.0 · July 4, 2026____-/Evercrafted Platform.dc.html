The Perfect System

One engine.

Not a larger version of what you have — a simpler one. One pipeline instead of three. One database instead of two. One AI backbone, and three faces that all draw from the same deterministic engine.

The central insight

Moodoor and Evercrafted are not two products. They are the consumer face and the creator face of the same engine.

The engine is the platform. The surfaces are how different audiences access it. What the perfect system adds is compression — the reduction of parallel systems into one coherent mechanism that feels like a single thing from every side.

The cardinal rule

AI interprets emotion.
Geometry places.

Two separate processes that never cross. Claude reads the feeling and names it. The deterministic engine — Mulberry32-seeded, R1–R18 governed — decides where every stem goes. Same seed, same layout, always.

The AI architecture

A clean division of labor

10

Claude API

claude-sonnet-4-6 · language
· EVS vector extraction · Territory narrative · Wreath critique + scoring copy · Listing copy (Etsy, Shopify) · Client intake synthesis (CDIE) · Design copilot + genome text

Flux · Replicate

Flux 1.1 Pro · pixels
· Photoreal render from Style DNA · Product image editing · Lifestyle / door / room scenes · Seasonal variant rendering · Mutated-genome renders

Deterministic

no AI · pure math
· Blueprint geometry (PIE, R1–R18) · Coordinate calculation · 6-metric scoring math · Genome encode / decode (WGS) · Inventory validation · Seasonal drift + coverage

Both AI providers called server-side only. API keys never reach the client. One locked system prompt per engine — prompts never cross functions.
