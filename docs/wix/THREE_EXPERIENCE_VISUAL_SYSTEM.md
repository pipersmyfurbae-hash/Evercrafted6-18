# Evercrafted Three-Experience Visual System

**Status:** Design direction approved; Wix global styles and pages not yet applied  
**Scope:** Evercrafted public editorial/commerce, Client SaaS public conversion plus workspace, and Personal private command.

## Shared Rules

The three experiences share a rigorous spacing scale, accessible component behavior, image quality standard, and interaction restraint. They do not share a header, marketing promise, color expression, or primary layout. The starting template’s bold colors, promotional voice, and typography are excluded from every final surface. The approved template hybrid informs only compositional dynamics: deliberate image sequencing, asymmetric editorial transitions, and a sense of motion across sections.

| System rule | Standard |
|---|---|
| Color | Neutral-first palette with muted accents reserved for state and hierarchy; no vivid template colors |
| Type | Legible sans-serif base everywhere; restrained serif display type only on Evercrafted editorial headlines and selected Client SaaS public titles |
| Motion | Short opacity/translation transitions, never looping decoration; all nonessential motion disabled for reduced-motion preference |
| Imagery | Authentic architectural, craft, product, and project imagery only; no decorative stock-influence collage style |
| Components | Visible focus, plain-language labels, semantic heading order, responsive states, and no hidden interaction-only navigation |
| Reviews | No ratings, testimonials, or customer-review modules until authentic, permissioned source material is supplied |

## 1. Evercrafted Editorial Brand and Commerce

Evercrafted is the calm public brand and commerce experience. Its role is to convey craft, material intelligence, enduring design, and considered collections. It uses the editorial hybrid most visibly, with visual pauses, full-width image moments, asymmetric case-study transitions, and quiet product curation.

| Element | Direction |
|---|---|
| Palette | Bone, limestone, smoked oak, deep graphite, and a minimal mineral accent; restrained contrast, never high-saturation promotional color |
| Typography | High-contrast serif only for primary editorial headlines; humanist sans-serif for navigation, product facts, forms, and commerce utility |
| Header | Minimal wordmark, editorial navigation, Store and Account utility; no Client SaaS workspace rail |
| Homepage | Full-bleed architectural opening, editorial split story, curated collections, Journal/Studio narrative, intentional commerce entry, quiet contact path |
| Collections | Large art-directed product images, generous margins, sparse filters, provenance-focused text, no discount-first merchandising blocks |
| Product page | Gallery as material story, concise specification panel, thoughtful pairing/collection relationship, reserved add-to-cart control |
| Footer | Journal, support, contact, policy, account, and social/brand utilities with no operational-client navigation |

## 2. Client SaaS Public Conversion and Workspace

Client SaaS is a product and operating environment, not a storefront. Its public layer earns trust through clarity: how work moves from request to review to delivery, what the product does, who it is for, and how access is provisioned. Its protected layer supports client work without editorial distraction.

| Element | Public conversion layer | Protected workspace layer |
|---|---|---|
| Palette | Cloud, off-white, graphite, and one muted functional accent | Soft white, cloud gray, graphite, and state-only accents |
| Typography | Confident sans-serif with selected restrained serif section titles | Highly legible sans-serif; serif only for page-title emphasis |
| Header/navigation | Product navigation: Platform, How It Works, Capabilities, Outcomes, Access, Sign In | Workspace rail, workspace switcher, project search, notifications, profile |
| Homepage | Outcome-led statement, workflow explanation, capability proof, access call to action | Workspace pulse, assigned work, reviews, delivery status, notifications |
| Content cadence | Clear product sections, diagrams and process stories, no Store catalog components | Dense-but-calm data modules, tables, filters, empty/loading/error states |
| Motion | Minimal reveal across content sections | Instant keyboard/navigation response; short state transitions only |

## 3. Personal Private Command

Personal is an owner-only internal command surface. It does not market, sell, or resemble a client workspace. It is intentionally more compact and data-led, with private context visible only after explicit owner authorization.

| Element | Direction |
|---|---|
| Palette | Charcoal, parchment, mineral gray, and understated status indicators |
| Typography | Compact sans-serif, with a restrained display line only for major command summaries |
| Navigation | Private left rail: Command, Private Projects, Integrations, Operations, Admin |
| Overview | Cross-workspace activity, private priorities, queued work, integration status, audit pulse |
| Operational views | Dense tables, status filters, clear escalation states, no public image storytelling |
| Guardrails | No route link in public or Client SaaS navigation; explicit owner policy on every page and backend query |

## Responsive and Accessibility Intent

On small screens, Evercrafted maintains image storytelling with shorter sections and legible material detail. Client SaaS collapses the workspace rail to a persistent menu and keeps essential actions accessible without hover. Personal prioritizes operational summaries and hides secondary details behind clearly labeled drawers. Every experience must retain visible focus, text contrast, keyboard operation, semantic headings, error messages, and a reduced-motion mode.
