# Evercrafted Release Checklist

## Required for any release candidate

- [ ] Roadmap, run log, change register, capability matrix, data dictionary, migration ledger, dependency register, risk register, and test matrix are current.
- [ ] Every included work item has linked test evidence and a documented status.
- [ ] Drizzle schema, migrations, fixtures/seeds, migration tests, repository helpers, and data documentation are aligned.
- [ ] Type checks, build, unit tests, integration tests, and applicable end-to-end checks pass.
- [ ] Tenant isolation, owner-only routes, and support audit paths have negative authorization evidence.
- [ ] Storage access, job recovery, webhooks/providers, and error states have documented validation.
- [ ] Security/privacy review and dependency review are current.
- [ ] Backup/restore and migration deployment/rollback limitations are documented.
- [ ] Release notes, monitoring, alerting, and support handoff are ready.
- [ ] Code, tests, documentation, and roadmap records are committed and the GitHub push/review status is recorded.
